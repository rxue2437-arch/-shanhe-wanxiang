# 山河万象·古代人生与帝国权谋模拟器

历史锚定型古代人生沙盘。你不是在扮演皇帝，你正在经历一个时代。

## 在线游玩

- [立即游玩（ChatGPT Sites）](https://shanhe-wanxiang.rxue2437.chatgpt.site)
- [GitHub Pages](https://rxue2437-arch.github.io/-shanhe-wanxiang/)

## 当前玩法

- 从唐、宋、明、清四个历史节点开始
- 六种出身与不同初始属性
- 季节、年份、年龄持续推进
- 历史大势、地方事件和个人抉择互相影响
- 命册、家门、天下与生平纪事
- 浏览器本地自动存档

## 本地运行

```bash
npm install
npm run dev
```

游戏仍会继续扩充事件、职业、婚姻、家族传承、仕途与战争系统。
